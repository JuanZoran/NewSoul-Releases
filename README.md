# NewSoul

Soul 插件

## 下载

- [GitHub Releases](https://github.com/JuanZoran/NewSoul-Releases/releases/latest)
- [蓝奏云](https://wwbnj.lanzoux.com/b007utki2d)，提取码 `3gin`

## 适配环境

- Soul：4.88.0、6.37、6.38（6.37 未实测）
- LSPosed：API 102

## 安装

安装公开版，在 LSPosed 中启用模块并勾选 Soul 作用域，重启 Soul
覆盖安装保留配置
